# Lifting Log

Mark's personal record of strength training: what he lifted, how hard it was, and how he felt,
detailed enough to track PRs and weekly volume per muscle.

## Structure

**Exercise**:
One specific movement variation in the library. Two variations are separate exercises whenever a PR on one wouldn't mean anything for the other.
_Avoid_: Lift, movement

**Session**:
One workout on one day at one place, with how Mark felt going in and how hard it was overall.
_Avoid_: Workout, training day

**Set**:
One continuous effort on one exercise, however many weights, sides, or pauses it contains. A drop set or a myo-rep set is one set.
_Avoid_: Round

**Segment**:
One uninterrupted piece of a set at one load on one side: load, full reps, and partial reps, or seconds for a hold.
_Avoid_: Mini-set (except as the myo-rep term), sub-set

**Superset**:
Two or more exercises done in alternating rounds, each set keeping its own line.
_Avoid_: Circuit, giant set

## Set types

**Warm-up set**:
A preparation set; it never counts toward PRs or volume.

**Regular set**:
A straight set to whatever effort was planned, including one that happened to reach RPE 10.
_Avoid_: Working set, straight set

**Failure set**:
A set deliberately taken to failure, usually ending in partial reps. Failure is a kind of set, not a rating.

**Drop set**:
One set whose segments step down in load without rest.

**Myo-rep set**:
One set made of an activation segment followed by short mini-set segments at the same load.

**Myo-match set**:
A set at a fixed load chasing a target rep count, with a segment for every break needed to reach it. Each myo-match set is its own set.

## Execution

**Execution mode**:
Whether a set was done bilateral (both sides together), alternating, or one side at a time.

**Load type**:
How an exercise's load number is read: total weight, per hand, bodyweight-based, or the machine's weight.

**Bodyweight share**:
The fraction of bodyweight a bodyweight exercise actually moves.

**Hold exercise**:
An exercise measured in seconds instead of reps.

**Gear**:
Equipment worn that doesn't change the exercise: belt, sleeves, shoes.
_Avoid_: Accessories

**Cue**:
A technique instruction Mark writes to his future self about an exercise.

## Effort and outcomes

**Readiness**:
How ready Mark felt at the start of a session, 1 to 10.
_Avoid_: Readiness RPE

**RPE**:
Rating of perceived exertion for a set, 1 to 10; Mark uses it for low-rep sets.

**RIR**:
Reps in reserve; Mark uses it for higher-rep sets. RIR equals 10 minus RPE.

**Session RPE**:
Overall effort of a whole session, 1 to 10.

**Reps to failure**:
Full reps plus RIR: how many reps the load would have allowed.

**e1RM**:
Estimated one-rep max, calculated from a regular or failure set's full reps and reps to failure. Every qualifying set gets its own estimate and the highest wins, whether it came from a single or a set of six.

**PR**:
A best result on an exercise from regular or failure sets: highest e1RM, heaviest load at exactly a rep count, or longest hold at a load.

**Main lift**:
One of the four primary barbell lifts (squat, bench press, deadlift, overhead press). Everything else is an accessory.
_Avoid_: Record (unqualified)

**Best set**:
The top drop, myo-rep, or myo-match set on an exercise, which never counts as a PR.

**Weekly volume**:
Sets per muscle per week. Every set except a warm-up counts: one for each primary muscle, half for each secondary.
_Avoid_: Hard set, working set
