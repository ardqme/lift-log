# Bodyweight lifts use a bodyweight share

Each bodyweight exercise stores the fraction of bodyweight it moves, cited from a published estimate, and its effective load is bodyweight × share plus the added (or minus the assisting) weight. Mark first rejected this convention in favor of logging only the added load, then restored it once it was clear that without it a pull-up at +0 has no meaningful e1RM and weighted and unweighted sets can't be compared. Bodyweight comes from the session or, if missing, the most recent earlier session.
