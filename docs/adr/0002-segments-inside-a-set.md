# A set holds a list of segments

One line in sets.jsonl is one set, and the set holds one or more segments (load, side, full reps, partial reps). A one-arm curl set with different reps per side, a three-weight drop set, and a myo-rep set are each a single set, which is how Mark counts them for volume. The alternative, one line per segment linked by a label, would have made a drop set look like three sets and spread one effort across many records that must stay consistent. Myo-match is the exception by definition: each myo-match set is its own line, with its breaks as segments.
